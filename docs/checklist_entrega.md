## Antes de publicar no GitHub

1. Use o ZIP `tech-challenge-fase-3-github.zip`.
2. Não suba os CSVs brutos; eles estão ignorados pelo `.gitignore`.
3. Confira seu nome/RM e, se desejar, adicione o link do vídeo no README após a gravação.
4. Se conseguir exportar a Silver completa, substitua `data/raw/alunos_silver.csv` no pacote local e reexecute a pipeline para atualizar as métricas do modelo individual.
