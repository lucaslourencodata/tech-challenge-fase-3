# Dados

Para reproduzir o projeto, coloque em `data/raw/`:

- `alunos_silver.csv`
- `indicador_alfabetizacao_municipio.csv`
- `metas_alfabetizacao_municipio.csv`
- `comparacao_meta_resultado_municipio.csv`
- `evolucao_alfabetizacao_municipio.csv`

Os arquivos são exportações das tabelas construídas na Fase 2. O pacote completo entregue ao aluno já contém esses arquivos, mas o `.gitignore` evita versioná-los no GitHub.
